Self-healing

Kill this pod on purpose

/crash ends this process instantly. Run this with plain Docker and the app stays dead. Run it under the Deployment in k8s/deployment.yaml and Kubernetes restarts it within seconds.

Crash this pod →
Scaling

One pod becomes several

kubectl scale deployment/cloudshift-web --replicas=5 turns this single process into five identical ones. The Service in front of them doesn't change — it just has more pods to hand traffic to.

Config

Nothing here is hardcoded

redis_host and flask_env above come from a ConfigMap, not from this file. Change the ConfigMap, restart the rollout, and every pod picks up the new values — no rebuild required.
